# F46 L3 Gold Standard Audit

F46 is eligible for L3 promotion only when the promotion head proves all of the following:

- Five distinct authorized-assessment roles for scope, reconnaissance planning, safe validation, risk assessment, and reporting
- Explicit authorization and approved rules-of-engagement gates
- Non-destructive validation and production-change prohibitions
- Defined stop conditions and evidence-integrity review
- Finding-confidence, remediation-plan, and retest-plan review
- Human approval required after automated gates and unable to override blockers
- Unit, integration, and adversarial authorization/governance tests
- Eight-scenario held-out reproducibility suite at 100% expected-behavior pass rate
- Minimal and complete clean-checkout examples
- Python 3.10, 3.11, and 3.12 CI green
- Python 3.12 held-out artifact publication
- Version 1.0.0, MIT license, citation metadata, security guidance, and reproducibility documentation

L3 means reference-quality reproducibility and reviewability for explicitly authorized, non-destructive assessment workflows. It does not grant authorization to test any system or permit destructive or uncontrolled activity.
